Spedi 0.2.0 — lokalny import zleceń i instalator Windows

- Dokument obok formularza: przypisywanie zaznaczonego fragmentu do wybranego pola.
- PDF z tekstem: osobny odczyt załadunku i rozładunku bez mieszania kolumn.
- Podgląd DOCX, XLS/XLSX/XLSM, CSV oraz obrazów i obrazu ze schowka.
- Wymagania POD i źródła pól zapisywane razem ze zleceniem; brakujące dane oznaczone ostrzeżeniem.
- Importowane zlecenia pozostają lokalne i są wyłączone z publikacji do usług zewnętrznych.
- Wbudowany Tesseract: PL, EN, DE, FR, IT; limit 2 GiB pamięci procesu OCR, dwa wątki i limit czasu.
- Polski i angielski interfejs oraz aktualizacje pozostałych modułów Spedi.

Pobierz **Spedi-Setup.exe**, uruchom instalator i korzystaj ze skrótu na pulpicie.
Nie wymaga instalowania Pythona ani używania terminala. ZIP to wersja przenośna:
rozpakuj cały katalog, a następnie uruchom Spedi.exe.

Przed aktualizacją zamknij Spedi. Wydanie zawiera wyłącznie program i jego zasoby,
bez baz użytkownika, dokumentów, konfiguracji kont i kluczy dostępowych.
Stary format DOC wymaga dodatkowo lokalnego LibreOffice lub zapisania pliku jako DOCX/PDF.
