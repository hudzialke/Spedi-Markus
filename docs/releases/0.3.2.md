# Spedi 0.3.2

- Poprawiono Listę OT: pojedyncza rekompensata oddana podczas późniejszego,
  wystarczająco długiego odpoczynku nie jest ponownie wymagana po rozpoczęciu
  nowej trasy. Stary termin nie cofa już terminu powrotu nowego cyklu.
- Historia wyliczenia nadal pokazuje zaliczenie rekompensaty po terminie.
  Niespłacone rekompensaty pozostają widoczne; tych samych godzin odpoczynku
  nie można wykorzystać do spłaty dwóch zobowiązań.
- Dodano testy regresji obejmujące nowy start tygodnia 1, spłatę pojedynczej
  rekompensaty po terminie i jednokrotne wykorzystanie dostępnego odpoczynku.
  Gotowy EXE i zainstalowany program przechodzą dodatkowy test tego przypadku
  przed opublikowaniem wydania na GitHubie.

Instalator aktualizuje pliki programu. Dane kierowców i zapisane scenariusze
pozostają w katalogu użytkownika.
