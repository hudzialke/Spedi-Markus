# Spedi 0.4.0

## English

- **All in backups:** save all module databases, DDD archives, attachments,
  default scenarios and reports in one portable 7z file. Lossless LZMA2
  compression is followed by SHA-256 verification of every file.
- Choose a folder or upload to your paired Google Drive account. Uploads retain
  the local backup. Credentials and service configuration are excluded.
- Restore directly from 7z, a legacy ZIP, an extracted backup folder or Google
  Drive. Restart Spedi to apply the restore; current data is backed up first.
  Managed DDD and attachment paths are adjusted for the destination computer.
- Brudnopis commands now use **Edit / DDD / View** menus. The Ewidentor and
  Dispatcher layouts are unchanged.
- Improved English text across backups, Google sign-in, profile history,
  updates, the daily overview, document import and POD workflows.
- Google Drive errors now show their cause and the next step. Drive access is
  checked before creating an upload backup.
- More reliable browser sign-in: unrelated local requests no longer stop the
  callback listener. Backup sign-in waits up to ten minutes and can be cancelled.
- Faster backup lists, less temporary disk I/O during 7z verification and a
  smaller Windows bundle after removing proven duplicate OCR libraries.
  Compression quality, checksums and OCR languages are retained.

The installer updates application files. Existing driver databases remain in
your user data folders. Google must be connected separately on another computer;
no external 7-Zip installation is needed.

## Polski

- **Backup All in:** bazy wszystkich modułów, archiwa DDD, załączniki oraz
  scenariusze i raporty z domyślnych katalogów programu w jednym pliku 7z.
  Bezstratna kompresja LZMA2 i kontrola SHA-256 każdego pliku po spakowaniu.
- Zapis do wybranego folderu lub na sparowany Dysk Google. Wysyłka zachowuje
  kopię lokalną. Dane logowania i konfiguracja usług pozostają poza archiwum.
- Przywracanie z 7z, starszego ZIP, rozpakowanego folderu lub Dysku Google.
  Zmiana następuje przy kolejnym uruchomieniu, z kopią obecnego stanu. Ścieżki
  do DDD i załączników są dostosowywane do nowego komputera.
- Menu **Edycja / DDD / Widok** w Brudnopisie. Układ Ewidentora i Dispatchera
  pozostaje bez zmian.
- Uzupełnione angielskie teksty backupu, logowania Google, historii profilu,
  aktualizacji, panelu dnia, importu dokumentów i obsługi POD.
- Dokładniejsze przyczyny błędów Google Drive i wskazówki rozwiązania problemu.
  Sprawdzenie dostępu do Drive przed tworzeniem kopii do wysłania.
- Poprawiony lokalny odbiór logowania Google: przypadkowe żądanie przeglądarki
  nie kończy oczekiwania. Logowanie z okna backupu czeka do 10 minut i można
  je anulować.
- Szybsze listy backupów, mniej zapisów tymczasowych podczas weryfikacji 7z
  i mniejszy pakiet Windows dzięki usunięciu potwierdzonych duplikatów bibliotek
  OCR. Kompresja, kontrola sum i języki OCR pozostają zachowane.

Instalator aktualizuje pliki programu. Bazy kierowców pozostają w katalogach
użytkownika. Na nowym komputerze trzeba osobno połączyć Google; instalacja
zewnętrznego 7-Zip nie jest potrzebna.
