# Spedi 0.2.2

## Polski

Naprawiono znikanie ostatniej aktywności z karty DDD, gdy odczyt nie zawiera
potwierdzonej godziny jej końca. Brudnopis i Analiza DDD zachowują teraz rodzaj
czynności i godzinę rozpoczęcia oraz pokazują, że koniec pozostaje nieznany.
Nie dopisują automatycznie czasu do północy ani do bieżącej godziny komputera.

W Brudnopisie przy ostatniej aktywności dostępny jest przycisk **Ustaw koniec…**.
Potwierdzona godzina jest zapisywana jako osobne uzupełnienie, widoczne w
zmodyfikowanym widoku i uwzględniane w Ewidentorze. Widok **Oryginał DDD**
zachowuje wyłącznie źródłowe przedziały. Nowsze dane DDD mają pierwszeństwo
przed takim uzupełnieniem.

Starsze profile odzyskują informację o ostatniej aktywności ze zweryfikowanych
archiwów po ich wybraniu lub ponownym dodaniu tego samego pliku. Historyczne
przedziały i ręczne korekty pozostają zachowane.

Zamknij Spedi przed uruchomieniem instalatora. Bazy użytkownika pozostają
w dotychczasowym katalogu danych, oddzielnie od plików aplikacji.

## English

Fixed a missing terminal activity when a driver-card download does not contain
a confirmed end time. Brudnopis and DDD Analyzer now retain its activity type
and recorded start, displaying the unknown end separately from measured totals.
They do not extend the activity to midnight or to the computer's current time.

Use **Set end…** in Brudnopis to enter a confirmed end time. This supplement is
stored separately from the raw DDD, included in the modified view and Ewidentor,
and superseded by newer source evidence. The original DDD view remains available.
Existing profiles recover terminal-change metadata from verified archives
without rewriting historical intervals or manual corrections.

Close Spedi before installing the update. Existing user data stays in its
separate application-data directory.
